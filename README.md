# Red Strike — Campaign Log

A running record of learning and playing **Red Strike** (VUCA Simulations, 2023) on Vassal with Eero.

## What's here

| Path | What it's for |
|---|---|
| `CLAUDE.md` | How Claude should help (rules questions, logging sessions). |
| `game.md` | Quick facts about the game and the Vassal module. |
| `players.md` | Who's playing, time zones, how we play. |
| `rules/` | Put the rulebook PDF(s) here. Claude reads these to answer rules questions. |
| `rules/rulings.md` | Rules questions we've hit, the answers, and where in the rules they come from. |
| `sessions/` | One file per session (after-action report). Start from `sessions/_template.md`. |
| `saves/` | Vassal save (`.vsav`) and log (`.vlog`) files. |
| `lessons.md` | Things we've learned, mistakes made, tips for next time. |

## How to use it

- **Before a session:** ask Claude to start a new session file for the scenario you're playing.
- **During play:** ask Claude rules questions. Answers get logged in `rules/rulings.md`.
- **After a session:** tell Claude what happened, roughly, in any order. Claude writes it up and updates `lessons.md`.
